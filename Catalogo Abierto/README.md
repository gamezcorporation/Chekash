# Catálogo abierto de productos de Venezuela (Chekash)

Lista de nombres, marcas, tamaños y formas escritas/habladas de productos de supermercado en Venezuela,
usada por la app **Chekash** para reconocer productos.

## Archivo

`seed_products_ve.json`: campos `id`, `name`, `brand`, `category`, `size`, `aliases`, `spoken`, `verified`, `source`.
